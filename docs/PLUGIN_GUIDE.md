# HQMW Cryosphere Plugin Guide

## Use in Windy

1. Open Windy Developer Mode.
2. Load the versioned URL generated by the `publish-plugin` workflow.
3. Open `HQMW Cryosphere` from the plugin menu.
4. Wait for the NASA GIBS catalog status to become ready.
5. Use Chinese theme filters, choose a product, and select `SHOW MAP`.

## Data Controls

- `更新图层`: reloads the NASA GIBS capabilities catalog.
- `刷新影像`: reloads the selected imagery layer.
- `TEST ALL`: tests one low-zoom NASA tile per catalog layer. Green means that test tile loaded, not that the layer is scientifically valid for Everest.
- `图例 / 单位`: opens NASA's product legend when supplied by the catalog.
- `定位珠峰`: changes only the map view; it does not assert a route, safety location, or exposure fact.

## Product Groups

- Cryosphere: freeze/thaw, frozen area, ice surface temperature, RTC Sentinel-1 SAR backscatter, snow products.
- Terrestrial hydrosphere: flood observation, historical flood hazard, dynamic surface water, soil moisture, reservoir inventory.
- Sentinel-2/HLS: HLS Sentinel-2 reflectance and DSWx-HLS surface water.
- Ocean reference: sea ice and sea-surface products. These are not Himalayan glacier products.

## Boundary

No GIBS raster can by itself confirm avalanche, icefall, landslide, flood, or any life-safety decision. Manual image-date comparison remains `UNKNOWN` until a separate validated change-analysis backend publishes evidence.
